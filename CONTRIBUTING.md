# Contributing

AI Learning Lab welcomes issues and pull requests.

## Good contributions

- Correct an explanation or improve a diagram/example.
- Add a reproducible practical implementation to a planned chapter.
- Add tests, setup instructions, measurements, or documented failure modes.
- Propose a chapter by opening an issue with its learning goal and practical project.

## Chapter standard

A completed chapter should include a clear explanation, runnable code, setup instructions, expected output, and at least one limitation or production trade-off. Avoid API keys and proprietary data in examples.

## Pull requests

Keep each pull request focused. Explain what changed, how to run it, and what you tested.
